# **E-Commerce Customer Segmentation & Churn Analysis | SQL, Python & Power BI**

*IKEA Gifting – Customer Analytics & RFM Segmentation*

---

### **Project Overview**
An end-to-end customer analytics project using two years of transaction data (2009–2011) to identify valuable customers, understand churn risk, and support targeted marketing and retention strategies.

### **Business Objectives**
- Identify high-value customer segments and their revenue contribution.
- Identify customers inactive for 90 days.
- Analyze customer trends across time and geography.
- Recommend targeted strategies for different customer segments.

### **Dataset**
- **Source:** Online Retail II – UCI Machine Learning Repository.
- **Period:** December 2009 – December 2011.

### **Tools & Technologies**
- **SQL:** Data cleaning, transformation, validation, and preparation.
- **Python:** Data analysis, RFM calculation, customer scoring, and segmentation using Pandas.
- **Power BI:** Interactive dashboard development, data modelling, DAX, and business insights.

### **Technical Skills Demonstrated**

**SQL**
- Database creation and table management.
- Combining datasets using `UNION ALL`.
- Data type conversion and handling missing values.
- Data cleaning, duplicate detection, and removal.
- Data validation using SQL queries and aggregations.

**Python**
- Data manipulation and cleaning using Pandas.
- RFM metric calculation and customer scoring.
- Customer segmentation using business-defined rules.
- Churn identification using a 90-day inactivity threshold.
- Data aggregation and export for Power BI reporting.

**Power BI**
- Interactive, multi-page dashboard development.
- Data modelling and table relationships.
- DAX measures and calculated columns.
- KPI cards and business performance indicators.
- Slicers, filters, drill-downs, and interactive navigation.
- Time-based and geographic analysis.
- Visualizations for customer segments, revenue contribution, and churn analysis.

### **Customer Segmentation – RFM Analysis**
Customers are evaluated using three key metrics:

- **Recency:** Number of days since the customer's last purchase.
- **Frequency:** Number of distinct purchase transactions.
- **Monetary:** Total revenue generated by each customer.

**Customer Segments:**
- Champions
- Loyal
- At Risk
- New
- Needs Attention
- Lost

### **Power BI Dashboard**
The interactive dashboard consists of three pages:

1. **Home & Navigation:** Dashboard introduction and navigation.
2. **Business Overview:** Overall business performance, revenue, and customer insights.
3. **RFM Analysis:** Customer segmentation, value distribution, and churn analysis.

### **Project Scope**
- Historical customer transaction analysis.
- Customer segmentation using RFM methodology.
- Customer inactivity identification using a fixed 90-day threshold.
- Interactive business intelligence reporting.

**Out of Scope:** Predictive churn modelling, real-time customer scoring, product recommendations, and campaign execution.
